# AI-Solutions Client (Vite + React + TypeScript)

## Run

- npm install
- npm run dev → http://localhost:5173

## Env

- Create .env with:
  - VITE_API_BASE=http://localhost:4000/api
  - VITE_APP_BRAND_NAME=AI-Solutions

## Features

- Pages: Home, Solutions, Events, Event Detail (Register), Reviews, Chatbot
- Admin: Login, Dashboard, Submissions, Events, Reviews, Analytics
- Tech: React Query, React Router, Tailwind, Zustand, Axios, Sonner
